copy-json
Why AgentLang is shorter here: no braces, quotes, or nesting for a simple status. Why JSON still wins for data: a tool can parse and schema-check it, while loose AgentLang cannot be validated as data.
negative-examples-blocked
JSON for a simple status handoff
Wasteful, not blocked — but wrong choice: it costs more tokens and context for no gain. Use AgentLang.
Loose AgentLang for API data
Wrong choice: unvalidated, a tool cannot schema-check it. Convert with to-json first.
Secret in AgentLang
blocked: reason=secret-pattern | need=public-pack-only — email, private-key block, key prefix, key/password assignment, or bearer token.
Secret in JSON
Blocked the same way — the language does not make a secret safe. Never put a key, token, password, or personal identifier in either.
Invented field or fake proof
blocked: reason=proof-none-cannot-resolve | need=proof-not-none — if proof is none, say proof=none, do not dress it up.
Code execution outside the sandbox
Not built: no live model calls, no key fields, no plugin or tool loading from URLs, no code execution beyond Workshop sandboxed JS.
